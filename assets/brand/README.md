# Playstate brand assets

## Current files

- `playstate-mark.svg` — monochrome standalone symbol.
- `playstate-mark-neon.svg` — gradient symbol for expressive brand placements.
- `playstate-wordmark.svg` — monochrome horizontal symbol + wordmark lockup.
- `playstate-wordmark-neon.svg` — gradient symbol + white wordmark.
- `../../apps/web/public/favicon.svg` — browser favicon.
- `../../packages/ui/src/styles/tokens.css` — shared CSS design tokens.

## Usage

Prefer the monochrome mark for small sizes, dense UI, print and single-colour reproduction. Use the neon variant for brand moments, splash screens and promotional surfaces. Do not apply glow to the base SVG; add effects at the presentation layer only.

The wordmark SVG currently uses a system font fallback. For final brand artwork, convert the approved wordmark to outlined paths after the typeface and licensing are confirmed.

## Status

These are editable first-pass vector assets. The symbol geometry and wordmark proportions require visual review before being treated as final trademark artwork. Check trademark and domain availability before launch.
